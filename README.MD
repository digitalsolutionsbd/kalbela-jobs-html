# 🏠 Kalbela Jobs - Jobportal Website

## 📋 প্রকল্প সারসংক্ষেপ

একটি আধুনিক, ব্যবহারকারী-বান্ধব এবং শক্তিশালী জব পোর্টাল ওয়েবসাইট যা বাংলাদেশ এবং আন্তর্জাতিক বাজারে চাকরিপ্রার্থী ও নিয়োগকর্তাদের মধ্যে সেতুবন্ধন তৈরি করবে। এটি চাকরির সন্ধান প্রক্রিয়া, আবেদন এবং নিয়োগ প্রক্রিয়াকে আরও সহজ ও কার্যকর করবে।

### 🎯 প্রকল্পের লক্ষ্য

- দ্রুত এবং নির্ভুলভাবে চাকরির তথ্য প্রদান
- চাকরিপ্রার্থী ও নিয়োগকর্তাদের জন্য একটি স্বাচ্ছন্দ্যময় অভিজ্ঞতা নিশ্চিত করা
- বাংলাদেশের চাকরির বাজারের চাহিদা অনুযায়ী কাস্টমাইজড ফিচার প্রদান
- মোবাইল-অপ্টিমাইজড ও অ্যাক্সেসিবল ইন্টারফেস নিশ্চিত করা

## 🌟 মূল ফিচারসমূহ

### 1. 👤 উন্নত ইউজার ও রোল ম্যানেজমেন্ট

#### ইউজার রোল সিস্টেম

-   **অ্যাডমিন**: সম্পূর্ণ ওয়েবসাইট নিয়ন্ত্রণ ও ব্যবস্থাপনা।
-   **নিয়োগকর্তা (Employer)**: চাকরির পোস্ট, আবেদনকারীদের ব্যবস্থাপনা, কোম্পানি প্রোফাইল তৈরি।
-   **চাকরিপ্রার্থী (Job Seeker)**: প্রোফাইল তৈরি, সিভি আপলোড, চাকরির জন্য আবেদন, চাকরির সন্ধান।

#### অ্যাডমিন ক্ষমতা

-   ✅ নতুন নিয়োগকর্তা ও চাকরিপ্রার্থী অনুমোদন/বাতিল।
-   ✅ চাকরির পোস্ট পর্যবেক্ষণ ও অনুমোদন।
-   ✅ ব্যবহারকারী ডেটা ম্যানেজমেন্ট।
-   ✅ প্ল্যাটফর্মের সেটিংস নিয়ন্ত্রণ।
-   ✅ রিপোর্ট ও অ্যানালিটিক্স অ্যাক্সেস।

#### নিয়োগকর্তা বৈশিষ্ট্য

-   ✅ চাকরির বিজ্ঞাপন পোস্ট করা।
-   ✅ আবেদনকারীদের প্রোফাইল দেখা ও ডাউনলোড করা।
-   ✅ আবেদনকারীদের স্ট্যাটাস (Selected, Rejected, Interview) আপডেট করা।
-   ✅ কোম্পানি প্রোফাইল তৈরি ও আপডেট করা।
-   ✅ চাকরির পোস্টের পারফরমেন্স ট্র্যাকিং।

#### চাকরিপ্রার্থী সুবিধা

-   ✅ বিস্তারিত প্রোফাইল তৈরি ও সিভি আপলোড।
-   ✅ কাস্টমাইজড চাকরির সন্ধান (ফিল্টার, কীওয়ার্ড)।
-   ✅ চাকরির জন্য সরাসরি আবেদন।
-   ✅ আবেদনের স্ট্যাটাস ট্র্যাকিং।
-   ✅ পছন্দের চাকরি সংরক্ষণ করা।

### 2. 💼 উন্নত জব পোস্টিং ও সার্চ

#### স্মার্ট জব পোস্টিং

-   ✅ **বিস্তারিত চাকরির বর্ণনা**: পদবি, কোম্পানির নাম, কাজের ধরন (ফুল-টাইম, পার্ট-টাইম), বেতন, অভিজ্ঞতা, শিক্ষাগত যোগ্যতা, প্রয়োজনীয় দক্ষতা।
-   ✅ **ক্যাটাগরি**: ইন্ডাস্ট্রি-ভিত্তিক (যেমন, IT, Finance, Marketing)।
-   ✅ **লোকেশন-ভিত্তিক পোস্টিং**: নির্দিষ্ট শহর বা অঞ্চলের জন্য।

#### অ্যাডভান্সড সার্চ ও ফিল্টার

-   ✅ **কীওয়ার্ড সার্চ**: পদবি, কোম্পানির নাম, দক্ষতা দ্বারা সন্ধান।
-   ✅ **ফিল্টার অপশন**: বেতন পরিসীমা, অভিজ্ঞতা, কাজের ধরন, শিক্ষাগত যোগ্যতা, প্রকাশনার তারিখ।
-   ✅ **লোকেশন-ভিত্তিক সার্চ**: গুগল ম্যাপ ইন্টিগ্রেশন সহ।

### 3. 📄 প্রোফাইল ও সিভি ম্যানেজমেন্ট

#### চাকরিপ্রার্থীর প্রোফাইল

-   ✅ **ব্যক্তিগত তথ্য**: নাম, ঠিকানা, যোগাযোগ।
-   ✅ **শিক্ষাগত যোগ্যতা**: ডিগ্রি, প্রতিষ্ঠান, পাসের সাল।
-   ✅ **অভিজ্ঞতা**: পূর্ববর্তী কাজের ইতিহাস, দায়িত্ব।
-   ✅ **দক্ষতা**: টেকনিক্যাল ও সফট স্কিল।
-   ✅ **সিভি আপলোড**: PDF ফরম্যাটে সিভি আপলোড ও ম্যানেজ করার সুবিধা।

#### নিয়োগকর্তার কোম্পানি প্রোফাইল

-   ✅ **কোম্পানির বিবরণ**: মিশন, ভিশন, শিল্প।
-   ✅ **লোগো ও ছবি আপলোড**: কোম্পানির ব্র্যান্ডিং।
-   ✅ **যোগাযোগের তথ্য**: ঠিকানা, ওয়েবসাইট, ফোন।
-   ✅ **চলমান ও পূর্ববর্তী চাকরির পোস্টের তালিকা।**

### 4. 🚀 অ্যাপ্লিকেশন ম্যানেজমেন্ট সিস্টেম

#### সহজ আবেদন প্রক্রিয়া

-   ✅ **এক-ক্লিক আবেদন**: আপলোড করা সিভি দিয়ে দ্রুত আবেদন।
-   ✅ **কভার লেটার**: কভার লেটার লেখার বা আপলোড করার অপশন।
-   ✅ **আবেদন ট্র্যাকিং**: আবেদন স্ট্যাটাস (Pending, Reviewed, Interview, Hired, Rejected) দেখার সুবিধা।

#### নিয়োগকর্তার জন্য আবেদন ড্যাশবোর্ড

-   ✅ **আবেদনকারীদের তালিকা**: প্রতিটি চাকরির পোস্টের জন্য।
-   ✅ **আবেদনকারীদের প্রোফাইল দেখা**: সিভি ডাউনলোড ও সংক্ষিপ্ত বিবরণ।
-   ✅ **আবেদন স্ট্যাটাস আপডেট**: ইন্টারভিউ শিডিউল, অফার লেটার।
-   ✅ **কমিউনিকেশন টুলস**: আবেদনকারীদের সাথে যোগাযোগ করার অপশন।

### 5. 🔔 নোটিফিকেশন ও অ্যালার্ট সিস্টেম

#### ব্যক্তিগত নোটিফিকেশন

-   ✅ **চাকরির সুপারিশ**: প্রোফাইল ও পছন্দের উপর ভিত্তি করে নতুন চাকরির বিজ্ঞপ্তি।
-   ✅ **আবেদনের স্ট্যাটাস আপডেট**: আবেদনের স্ট্যাটাস পরিবর্তন হলে নোটিফিকেশন।
-   ✅ **ইন্টারভিউ রিমাইন্ডার**: ইন্টারভিউয়ের তারিখ ও সময় সম্পর্কে স্মরণ করিয়ে দেওয়া।

#### নিয়োগকর্তার জন্য নোটিফিকেশন

-   ✅ **নতুন আবেদন**: চাকরির পোস্টে নতুন আবেদন জমা পড়লে।
-   ✅ **পোস্টের মেয়াদ**: চাকরির পোস্টের মেয়াদ শেষ হওয়ার আগে নোটিফিকেশন।

## 🚀 ব্যবহারবিধি (Usage)

এই প্রকল্পটি আপনার লোকাল মেশিনে সেটআপ এবং চালানোর জন্য নিচের ধাপগুলো অনুসরণ করুন:

### পূর্বশর্ত (Prerequisites)

আপনার সিস্টেমে নিম্নলিখিত সফটওয়্যারগুলো ইনস্টল করা থাকতে হবে:

-   **Git**: [https://git-scm.com/](https://git-scm.com/)
-   **Node.js** এবং **npm** (Node.js ইনস্টল করলে npm স্বয়ংক্রিয়ভাবে ইনস্টল হয়ে যাবে): [https://nodejs.org/](https://nodejs.org/)

### সেটআপ এবং চালানো (Setup and Run)

1.  **রিপোজিটরি ক্লোন করুন**:
    প্রথমে আপনার টার্মিনাল বা কমান্ড প্রম্পট ওপেন করুন এবং এই কমান্ডটি ব্যবহার করে প্রোজেক্ট রিপোজিটরি ক্লোন করুন:
    ```bash
    git clone [https://github.com/digitalsolutionsbd/kalbela-jobs-html](https://github.com/digitalsolutionsbd/kalbela-jobs-html)
    ```

2.  **প্রোজেক্ট ডিরেক্টরিতে যান**:
    ক্লোন করার পর, প্রোজেক্ট ফোল্ডারে নেভিগেট করুন:
    ```bash
    cd kalbela-jobs-html
    ```

3.  **ডিপেন্ডেন্সি ইনস্টল করুন**:
    প্রোজেক্টের প্রয়োজনীয় নোড মডিউলগুলো ইনস্টল করতে নিম্নলিখিত কমান্ডটি চালান:
    ```bash
    npm install
    ```

4.  **Tailwind CSS ওয়াচার শুরু করুন**:
    Tailwind CSS ফাইলগুলো কম্পাইল এবং পরিবর্তনগুলো পর্যবেক্ষণ করতে এই কমান্ডটি ব্যবহার করুন। এটি `dist` ফোল্ডারে আপনার CSS ফাইল তৈরি করবে:
    ```bash
    npm run watch
    ```
    *এই কমান্ডটি চালানোর পর টার্মিনালটি খোলা রাখুন, কারণ এটি ফাইল পরিবর্তনের সাথে সাথে CSS পুনরায় কম্পাইল করবে।*

5.  **লাইভ সার্ভার ব্যবহার করে ওয়েবসাইট দেখুন**:
    এখন আপনার পছন্দের লাইভ সার্ভার এক্সটেনশন (যেমন, VS Code-এর "Live Server" এক্সটেনশন) ব্যবহার করে `index.html` ফাইলটি ওপেন করুন।

    *যদি আপনার লাইভ সার্ভার এক্সটেনশন না থাকে, তবে VS Code-এ "Live Server" এক্সটেনশনটি ইনস্টল করুন এবং `index.html` ফাইলটির উপর রাইট-ক্লিক করে "Open with Live Server" অপশনটি নির্বাচন করুন।*

    ওয়েবসাইটটি আপনার ডিফল্ট ব্রাউজারে চালু হবে এবং আপনি `npm run watch` কমান্ডের মাধ্যমে Tailwind CSS-এর পরিবর্তনগুলো রিয়েল-টাইমে দেখতে পারবেন।# kalbela-jobs-html
